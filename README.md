# Kaggle Survey Data Analysis Project

## Project Overview

This project analyzes the Kaggle Machine Learning and Data Science Survey dataset using Microsoft Excel.

The project demonstrates a complete data analysis workflow, including data cleaning, transformation, exploration, and visualization.

## Tools Used

- Microsoft Excel
- Power Query
- Power Pivot
- PivotTables
- PivotCharts
- Excel Dashboard

## Dataset

The dataset is based on the Kaggle Data Science and Machine Learning Survey.

## Project Objectives

- Clean and prepare the survey data
- Explore patterns and trends in the dataset
- Analyze responses across different categories
- Create meaningful KPIs and visualizations
- Develop an interactive Excel dashboard
- Present data-driven insights clearly

## Analysis Workflow

1. Data cleaning and preparation using Power Query
2. Data transformation and organization
3. Data modeling using Power Pivot
4. Exploratory analysis using PivotTables
5. Data visualization using PivotCharts
6. Dashboard development
7. Extraction of key insights

## Dashboard

The project includes an interactive Excel dashboard designed to present the main findings from the analysis.

## Key Insights

- The survey contains **63,612 total responses**, with **India contributing the largest number of responses (15,054)** among the displayed countries.
- **Computers/Technology** is the leading industry among the analyzed responses, representing **62%**, followed by **Academics/Education (22%)** and **Accounting/Finance (16%)**.
- **GPUs** are the most commonly reported specialized hardware, accounting for **56%**, followed by **CPUs (39%)** and **TPUs**.
- **Python** is consistently one of the most used programming languages across the analyzed data science roles and is also frequently recommended by respondents.
- **Data Scientist** and **Data Analyst** roles show strong representation across programming-language usage and recommendations.
- Among the BI tools displayed, **Tableau, Microsoft Power BI, and Google Data Studio** show different adoption patterns across countries, with notable variation between regions.
- The salary analysis shows substantial differences in reported compensation across data-related job roles, with **Data Scientist** showing a high average yearly compensation in the displayed analysis.
- **Coursera** appears as the most prominent platform for data science courses across the years shown, while other platforms such as DataCamp, edX, Udacity, and Udemy show varying levels of usage.
